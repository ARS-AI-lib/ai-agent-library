# Presentation

`ai-agent-library-presentation.html` — สไลด์แนะนำระบบ ความยาวพูดจริงราว 5-6 นาที
ทำไว้สำหรับผู้ฟังผสม (ผู้บริหารที่ไม่ได้สายเทคนิค + ทีม Dev/Product)

## วิธีใช้
เปิดด้วยเบราว์เซอร์ตรงๆ ได้เลย ไม่ต้องมีเน็ต ไม่ต้องรันเซิร์ฟเวอร์ · เลื่อนทีละสไลด์
(scroll-snap) · รองรับทั้งโหมดสว่างและมืดตามเครื่องผู้ชม

## ทำไมไฟล์ถึงใหญ่ (2.3MB)
**self-contained ทั้งหมดโดยตั้งใจ** — วิดีโอเดโม 3 คลิป, ภาพหน้าจอ 2 รูป, ฟอนต์
IBM Plex Sans Thai Looped ทั้งชุด และโลโก้ ถูกฝังเป็น base64 ในไฟล์เดียว
`external request = 0` ตรวจแล้ว

เหตุผล: ต้องเปิดได้แน่นอนในห้องประชุมที่เน็ตใช้ไม่ได้ หรือบนเครื่องคนอื่น และไม่ต้อง
พึ่ง CDN ที่อาจโดนบล็อกในเครือข่ายองค์กร

## ⚠️ ถ้าจะแก้วิดีโอ
วิดีโอต้องเป็น **H.264 (`avc1`)** เท่านั้น — ไฟล์ `.mov` ที่อัดจาก macOS เป็น HEVC
(`hvc1`) ซึ่ง **Chrome เล่นไม่ได้ จะขึ้นจอดำ** แปลงด้วย `avconvert` ที่มีมากับ macOS:

```bash
avconvert --preset PresetHighestQuality --source in.mov --output out.mp4 --replace
```

คลิปทั้ง 3 มีแถบดำบน/ล่างข้างละ 19px ติดมาจากการอัดหน้าจอ ถูกครอบออกด้วย
`margin-top: -1.979%` — ค่านี้คิดจาก **19/960 (เทียบความกว้าง)** ไม่ใช่ 19/540
เพราะ CSS คิด margin เป็น % จากความกว้างของ container เสมอ
